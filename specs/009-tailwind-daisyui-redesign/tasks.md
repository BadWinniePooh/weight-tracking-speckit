## Notes

- `[P]` tasks touch different files with no inter-task data dependency — safe to run in parallel
- US7 (Phase 2) is a **constitutional requirement** — the spec marks it P1 and as a non-negotiable prerequisite. Do not skip or defer it.
- The `logout-button` id is preserved across all navbar implementations (existing tests depend on it)
- The Chart.js canvas (`#chart-canvas`, `#chart-container`) must NOT have DaisyUI card classes applied over it — only the surrounding `<section>` wrapper
- `theme.ts` must be called as early as possible in each page (first import in each TS entry point) to prevent flash of unstyled content on theme switch
- Commit after completing each phase per the constitution's commit cadence requirement
