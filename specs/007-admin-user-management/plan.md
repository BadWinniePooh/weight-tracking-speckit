# Implementation Plan: Admin & User Management with Email Infrastructure

**Branch**: `007-admin-user-management` | **Date**: 2026-03-15 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/007-admin-user-management/spec.md`

## Summary

Adds SMTP email infrastructure, password reset, user self-service (username/password/email changes), email confirmation for new accounts, admin user management API, an append-only admin audit log, a daily background deletion service, and new API client typings in the frontend. All UI pages are deferred to iteration 008. Backend implemented strictly with Ports and Adapters; TDD throughout with MailHog Testcontainers for email verification.

## Technical Context

**Language/Version**: C# 12 / .NET 8 (backend); TypeScript 5.x / ES2020 (frontend — api-client.ts only)
**Primary Dependencies**: ASP.NET Core Minimal API, EF Core 8, Npgsql, BCrypt.Net-Next, MailKit 4.x (new), Testcontainers 3.10.0 + MailHog generic container (new)
**Storage**: PostgreSQL 16 — adds `PasswordResetTokens`, `EmailConfirmationTokens`, `AuditLog` tables; alters `Users` table
**Testing**: xUnit + WebApplicationFactory + Testcontainers.PostgreSql + Testcontainers generic (MailHog) — all in WeightTracker.Tests
**Target Platform**: Linux container (Docker Compose); development on macOS/Windows
**Project Type**: Web service (REST API)
**Performance Goals**: Audit log query < 1s for 10,000 entries with filters; background deletion job non-blocking to normal app traffic
**Constraints**: Anti-enumeration on password reset (response must be identical for known/unknown email); token values never stored plaintext; admin cannot act on own account
**Scale/Scope**: Single-tenant personal-health app; up to 10,000 users per deployment

## Complexity Tracking

| Deviation | Why Needed | Simpler Alternative Rejected Because |
|-----------|------------|--------------------------------------|
| MailKit instead of System.Net.Mail | System.Net.Mail is officially deprecated on .NET 6+; STARTTLS negotiation broken in some .NET runtime versions | Standard library choice; MailKit is 1 NuGet package with no further abstraction required |
| 5 new domain ports (IEmailService, IPasswordResetService, IEmailConfirmationService, IUserManagementService, IUserDeletionService) | Ports and Adapters is a stated architecture constraint; each port represents a distinct bounded capability | Combining into fewer interfaces would violate ISP and make individual service testing harder |
| MailHog Testcontainer in ApiFixture | SMTP integration must be verified end-to-end; no way to assert email delivery without a real SMTP stub | Mock IEmailService would only confirm the interface was called, not that the SMTP adapter works correctly |
| AuditLog has no FK on ActorUserId/TargetUserId | Preserve audit history after user deletion; deleting an admin should not cascade-delete their audit records | Nullable FK with SET NULL on delete could lose the historical user ID; storing as plain Guid preserves the identifier |
