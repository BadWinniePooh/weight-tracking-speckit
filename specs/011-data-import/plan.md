# Implementation Plan: Weight Data Import

**Branch**: `011-data-import` | **Date**: 2026-03-17 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/011-data-import/spec.md`

## Summary

Add a CSV file import capability that allows authenticated users to upload historical weight entries from their Profile page. A new `POST /api/import` backend endpoint accepts a multipart file upload, parses CSV rows, validates each independently, detects duplicates by date, bulk-inserts valid entries, and returns a structured result summary. The profile page gains an "Import Data" section with a file picker, submit button, and per-row error reporting.

## Technical Context

**Language/Version**: C# 12 / .NET 8 (backend); TypeScript 5.x / ES2020 (frontend)
**Primary Dependencies**: ASP.NET Core Minimal API, EF Core 8 + Npgsql; Vite 5.x, Tailwind CSS v3, DaisyUI v4 (frontend — no new packages needed)
**Storage**: PostgreSQL 16 — no schema changes; new repository method only
**Testing**: xUnit + WebApplicationFactory + Testcontainers.PostgreSql (backend); Vitest 2.x + jsdom (frontend)
**Target Platform**: Linux server (Docker Compose)
**Project Type**: Web service (REST API) + Web application (SPA)
**Performance Goals**: Import of 1,000 rows completes in under 5 seconds
**Constraints**: File size ≤ 5 MB; no new NuGet or npm packages; no schema migrations
**Scale/Scope**: Personal-use; single-user imports of up to several hundred rows in typical case
